# Guia Geral

## Execução do projeto

1. Instalar dependências: `.venv/bin/pip install -r requirements.txt`
2. Baixar dataset: `.venv/bin/python src/data_loader.py`
3. Treinar: `.venv/bin/python src/train.py`
4. Avaliar: `.venv/bin/python src/evaluation.py`
5. Subir API: `.venv/bin/python src/app.py`
6. Abrir slides: `presentation/slides/index.html`

## Navegação dos slides
Setas, espaço, F tela cheia, T tema, M menu, Home/End.
